# CloudQA Dynamic Web Automation

A .NET 10 console project for validating selected fields on a web form with Selenium WebDriver and Chrome.

## Project layout

- `src/DynamicWebAutomation/` - console application and its configuration.
- `tests/DynamicWebAutomation.Tests/` - xUnit tests for plain-data detection and scoring logic.
- `test-pages/` - local HTML pages used for later compatibility checks.
- `reports/` - generated run reports and failure screenshots; excluded from git.

Run instructions and the detection approach will be completed with the implementation.
